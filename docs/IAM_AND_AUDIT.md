# 身份访问管理透传与审计回传

数据平台不保存用户密码、成员关系、角色、API 密钥或产品授权事实。核心平台（Core）代理请求时透传组织标识 `organization_id`、项目标识 `project_id`、主体标识 `principal_id`、权限范围 `permission_scopes`、请求标识 `request_id`、追踪标识 `trace_id` 和幂等键 `idempotency_key`，数据平台使用核心平台信任的短期服务凭据验证调用来源，并对领域资源执行独立权限校验。

数据集创建/发布/删除、标注复核、数据导出、权限变更和敏感数据删除必须记录 UTC 时间、操作者、组织、项目、请求/追踪 ID、动作、资源、前后状态以及操作结果。审计事件通过版本化事件或服务 API 回传核心平台统一查询入口；回传失败进入发件箱（Outbox）重试和死信处理队列，不阻断已提交的业务事实，但必须触发运维告警。
