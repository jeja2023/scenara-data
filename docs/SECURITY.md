# 安全与隐私

数据平台处理原始媒体样本、人脸/人体相关数据、轨迹来源、标注、难例、授权和审计信息，默认按敏感数据管理。

- 使用 Core 平台统一身份和短期服务凭据，不保存密码、成员关系、角色或 API 密钥事实。
- 每次访问按组织、项目、主体和权限范围授权，来源为 Core 平台不等于自动放行。
- 难例只接收已批准、已授权、已脱敏且摘要可验证的内容。
- 外部 URL、压缩包和媒体输入防护 SSRF、路径穿越、压缩炸弹、恶意文件和资源耗尽。
- 密钥不得进入代码、镜像、日志、测试夹具或发布证据。
- 删除流程必须覆盖对象副本、派生索引、导出文件和审计记录中的可识别信息，并保留合规所需的删除证据。
