# 安全与隐私

Data 处理原始媒体样本、人脸/人体相关数据、轨迹来源、标注、难例、授权和审计信息，默认按敏感数据管理。

- 使用 Core 统一身份和短期服务凭据，不保存密码、Membership、Role 或 API Key 事实。
- 每次访问按 organization、project、principal 和 permission scopes 授权，来源为 Core 不等于自动放行。
- Hard Sample 只接收已批准、已授权、已脱敏且摘要可验证的内容。
- 外部 URL、压缩包和媒体输入防护 SSRF、路径穿越、压缩炸弹、恶意文件和资源耗尽。
- 密钥不得进入代码、镜像、日志、测试夹具或发布证据。
- 删除流程必须覆盖对象副本、派生索引、导出文件和审计记录中的可识别信息，并保留合规所需的删除证据。
