# 安全与隐私保护规范

数据平台负责处理原始媒体样本、人脸与人体生物特征相关数据、轨迹来源、标注信息、难例反馈、数据授权和审计记录，默认按敏感隐私数据级别实施严格防护。

- **身份与访问管理**：全面采用核心平台（Core）统一身份鉴权与短期服务访问凭据，本平台不单独持久化存储用户密码、成员关系、角色配置或 API 密钥事实。生产路径在 Bearer 服务凭据之外，强制验证独立 `SCENARA_DATA_REQUEST_CONTEXT_SIGNING_KEY` 对身份上下文签发的 300 秒 HMAC 声明；该密钥不得与服务令牌复用。
- **租户与项目隔离授权**：每一次 API 请求必须按组织标识（`organization_id`）、项目标识（`project_id`）、主体标识（`principal_id`）和权限范围（`permission_scopes`）执行细粒度鉴权，调用来源即使标记为核心平台也不等于自动放行。
- **难例数据安全交接**：难例数据只接收已经核心平台审批、已取得合法授权、已完成隐私脱敏且 SHA-256 清单摘要校验完全一致的受控内容。
- **外部输入与媒体防护**：对外部 URL 资源、压缩数据包和媒体上传流建立纵深防御，全面防范服务端请求伪造（SSRF）、目录穿越、压缩炸弹、恶意二进制文件以及资源耗尽拒绝服务攻击。
- **凭据与敏感信息管理**：任何服务密钥、加密证书或通信令牌严禁硬编码进入代码仓库、Docker 镜像、运行日志、测试夹具或发布证据中。
- **工作台会话**：独立工作台只将登录令牌保存在 `sessionStorage`，不持久化到 `localStorage`；生产默认关闭本地用户名密码入口，并由 Core 门户和网关统一限流、身份验证及会话撤销。
- **合规删除与隐私遗忘**：数据删除流程必须完整覆盖对象存储副本、派生特征索引、导出临时文件和审计日志中的个人可识别信息（PII），同时依法合规保留不可篡改的删除审计记录。
