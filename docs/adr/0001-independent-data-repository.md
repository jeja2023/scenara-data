# ADR-0001：建立独立 Data 责任仓库

- 状态：Accepted，实施中
- 日期：2026-08-15
- 负责人：Scenara Data
- 复审日期：2026-09-15

决定建立 `scenara-data`，但成熟度保持 `seed`，直到领域模型、契约、数据库/对象存储、IAM、审计、迁移、容量、备份、恢复和安全门禁全部具有可复现证据。

建仓不等于完成拆分。Core 现有 Dataset 能力仍是迁移来源，正式所有权切换必须经过 DataPlatformClient、影子读、摘要核对、短期同步、回滚窗口和旧写路径退役。任何长期双写、共享数据库表或源码导入均被禁止。
