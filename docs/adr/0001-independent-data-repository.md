## 决策背景与内容

决定建立独立的代码仓库 `scenara-data`，当前成熟度为已实现（`implemented`）：领域模型、契约消费、数据库/对象存储基础设施边界、身份访问管理接入、审计追踪、离线迁移导入和单元测试已具备完整的代码实现与测试证据。目标环境资格、容量压测、备份容灾恢复和跨仓库正式切流证据未完成前，严禁提前提升为已合格（`qualified`）或生产就绪（`production_ready`）。

建仓不等于完成系统拆分。核心平台（Core）现有的数据集处理能力仍是历史数据的迁移来源，正式所有权切换必须经过数据平台远程客户端（`DataPlatformClient`）、影子读对比、清单摘要核对、短期同步、回滚观察窗口和旧写路径正式退役。严禁任何形式的长期双写、共享底层数据库表或跨仓库源码导入。
