# ADR-0001：建立独立数据责任仓库

- 状态：已接受，实施中
- 日期：2026-08-15
- 负责人：景枢数据
- 复审日期：2026-09-15

决定建立 `scenara-data`，当前成熟度为 `implemented`：领域模型、契约消费、数据库/对象存储边界、IAM、审计、迁移导入和单元测试已具备代码证据。目标环境资格、容量、备份恢复和跨仓库切流证据未完成前，不得提升为 `qualified` 或 `production_ready`。

建仓不等于完成拆分。Core 平台现有数据集能力仍是迁移来源，正式所有权切换必须经过 `DataPlatformClient`、影子读、摘要核对、短期同步、回滚窗口和旧写路径退役。任何长期双写、共享数据库表或源码导入均被禁止。
