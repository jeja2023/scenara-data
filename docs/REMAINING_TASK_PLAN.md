# 景枢数据平台剩余任务计划

- **适用规范**：《景枢平台总体开发规范》`1.3.0`
- **当前版本**：`0.1.10`
- **当前成熟度**：已实现（`implemented`，尚未达到 `qualified` 或 `production_ready`）

## 一、 已完成功能基线

以下核心能力已经由本仓库源代码和自动化回归测试覆盖：

- 数据集（Dataset）、数据集版本（Dataset Version）、样本（Sample）、标注（Annotation）、质量（Quality）、血缘（Lineage）、难例（Hard Sample）、构建器（Builder）和标注提供方（Provider）。
- 内部业务 API（`/internal/v1/`）、租户与项目作用域隔离、写操作幂等控制、审计快照、统一错误信封、请求链路追踪和事件发件箱（Outbox）。
- PostgreSQL 数据库版本化迁移、内存存储适配器、S3 对象存储适配器、Redis 任务适配器以及离线迁移包导入工具。
- 难例交接（`hard-sample-handoff`）与数据集版本输出（`dataset-version-input`）的已发布契约校验，以及核心平台 ASGI 端到端回归测试；已适配布控误报复核（`scenara.portrait.surveillance-review.v1`）等难例场景。
- PostgreSQL 归档触发器、迁移版本成员恢复和五种样本 split 的前向兼容数据库迁移；难例导入失败记录可重试，生产编排和静态安全门禁。

## 二、 剩余交付任务列表

| 任务编号 | 当前状态 | 任务内容描述 | 责任边界 | 验收交付证据 |
| :--- | :--- | :--- | :--- | :--- |
| **DATA-P1** | 已实现（implemented） | 完成核心平台导出迁移包在真实 PostgreSQL/S3 上的全量导入、数据条数/业务 ID/SHA-256 摘要影子比对 | 数据平台 + 核心平台 | 附带清单与校验和的迁移比对报告、重复幂等导入验证报告 |
| **DATA-P2** | 已实现（implemented） | 完成样本、标注、质量、血缘在真实基础设施环境上的并发读写、版本冻结、失败重试与容灾恢复演练 | 数据平台 | 集成测试运行日志、灾难恢复报告、权限越权拦截与审计日志查询记录 |
| **DATA-P3** | 本仓已实现，待目标环境演练 | 全量备份/恢复、对象巡检、只读压测、Outbox 死信重建和部署前报告工具 | 数据平台 / 部署团队 | 恢复点目标（RPO）与恢复时间目标（RTO）测试报告、容量增长曲线、消息队列重建记录 |
| **DATA-P4** | 本仓已实现演练入口，待 Core 切流 | 影子读比对、旧路径只读、正式远程切流与回滚窗口由 Core 路由执行 | 核心平台 + 数据平台 | 流量比对证明、正式切流与回滚演练日志、原有写路径退役归档记录 |
| **DATA-P5** | 本仓已实现，待 Model 联调 | 生产签名身份上下文、完整模型访问授权筛选及本地签名工具 | 数据平台 + 模型平台 | 服务间鉴权通过/拒绝日志、不可变清单摘要校验通过、无数据库直连访问证明 |
| **DATA-P6** | 已规划（planned） | 扩展公共 API 或领域事件目录时，同步发布契约仓库（`scenara-contracts`）新版本并完成四仓协同升级 | 数据平台 + 契约仓库 | 正式发布的契约包版本、跨仓兼容性矩阵和版本迁移说明文档 |

## 三、 执行依赖顺序

```text
DATA-P1（迁移导入与比对） -> DATA-P2（集成演练与冻结） -> DATA-P3（备份恢复与压测） -> DATA-P4（正式切流与退役）
                                            \-> DATA-P5（模型平台对接） -> DATA-P6（契约协同升级，按需触发）
```

在未取得真实生产基础设施、备份恢复演练和全量切流证据前，本仓库成熟度保持为 `implemented`（已实现），严禁提前声明为 `qualified`（已合格）或 `production_ready`（生产就绪）。
